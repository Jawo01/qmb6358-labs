A lagged variable carries last quarter's sales over into this quarter's model; you get it by shifting the sales column down by one row, and the data file calls it Lag.Sales Lecture 4a · slides 10–11. 4Test on a year the model has not seen

R² only tells you how well a model fits the quarters it has learned from. The book's rule is to test a model on data it did not use, and for a time series that test has to be a time-based split, i.e. predicting the future from the past §6.7.2 · p. 314. Novikov makes the same point about separate training and test data Novikov · p. 19. Below, each model is fitted on 1986 to 1998 (t ≤ 52) and then forecasts 1999. The simple baseline "same quarter last year" competes as well, since a model should first beat a baseline §6.9.5 · p. 324. Please compare the models.

5A number or a range

A forecast presented as a single number creates false precision, and the book asks for a range that supports planning choices §6.5.4 · p. 306. Suppose that you plan bottling capacity for Q1-00, where unused capacity is expensive, while extra capacity can be added on short notice at a premium. Please choose a base plan.

When must the model be refit?

Forecast ranges also tell you when a model stops working. A structural break, such as a new competitor or a major pricing change, can make a model that looked accurate unreliable very quickly, and a forecasting team should say in advance what would invalidate its forecast §6.5.6 · p. 307. Novikov calls this drift, and he describes how retail forecasting models trained before 2020 had to be retrained quickly when the pandemic changed demand Novikov · pp. 83–84.
